This guide helps you resolve common issues with MatchOps.

## Data Issues

### Data Not Saving

**Problem**: Changes aren't persisting between sessions.

**Solutions**:
- Check the sync status: if it shows **Error**, tap the indicator to retry
- Make sure your phone has free storage space
- Everything saves automatically. **Quick Save** in the match menu saves right away if you want to be sure

### Lost Data

**Problem**: Previous games or players have disappeared.

**Causes**:
- App data was cleared in Android settings
- App was uninstalled and reinstalled
- Using a different device than before

**Recovery**:
- Sign out and sign back in to re-sync from your account
- Check that you are signed in with the same account as before
- If you use a legacy setup without an account, restore from a backup if available
- Contact support if data should exist

### Import/Export Not Working

**Problem**: Can't restore a backup or export data.

**Solutions**:
- Only a MatchOps backup (a JSON file) can be restored. Excel files cannot be imported.
- Make sure the file isn't corrupted (try another backup or an automatic restore point)
- If saving the file fails, choose **Share** (for example to email or a cloud folder) or **Save** when you make the backup

## Cloud Sync Issues

### Data Not Syncing

**Problem**: Changes made on one device don't appear on another.

**Solutions**:
1. Check your internet connection
2. Look for sync status indicator - if it shows "Pending", wait for sync to complete
3. Close and reopen the app
4. Verify you're signed into the same account on both devices
5. Try signing out and back in

### Sync Stuck or Failing

**Problem**: Sync indicator shows pending changes that won't sync.

**Solutions**:
1. Check internet connection
2. Wait a few minutes - the app retries automatically
3. Close and reopen the app
4. If still stuck, try signing out and back in

<Callout type="info">
If you have pending changes and go offline, they're safely stored and will sync when you reconnect.
</Callout>

### Offline with Cloud Account

**Problem**: Worried about using the app offline with a cloud account.

**This is normal and works fine!**
- All changes save to your device immediately
- Data syncs automatically when you reconnect
- No data is lost during offline periods
- You can track entire games without internet

<Callout type="tip">
The app is designed to work offline. Track your game, and everything syncs when you're back online.
</Callout>

## Authentication Issues

### Can't Sign In

**Problem**: Unable to log into your account.

**Solutions**:
1. Verify email and password are correct
2. Check if Caps Lock is on
3. Try the **Forgot password?** link
4. Check your internet connection
5. If the account is new, make sure you entered the verification code from your email

### Forgot Password

**Problem**: Can't remember your password.

**Solution**:
1. On the sign-in screen, tap **Forgot password?**
2. Enter your email address and tap **Send Reset Email**
3. Check your email (including the spam folder)
4. Type the code at **Enter Reset Code** and set a new password
5. Sign in with the new password

### Session Expired

**Problem**: App asks you to sign in again unexpectedly.

**Causes**:
- A session expires after a long period of inactivity

**Solution**: Simply sign in again. Your data is safe in the cloud.

### Account Creation Problems

**Problem**: Can't create a new account.

**Solutions**:
- Check that email address is valid
- The password must be at least 8 characters
- Check internet connection
- Try a different email address if issues persist

## The match and the plan

### Who is here? does not let me mark absences

Absences can only be marked before kick-off. If the clock has started or the match has events, change the squad in **Match details**.

### The large clock does not show the next change

The **Next change** block shows when the game has a plan. A game created without a plan does not show it.

### Finish this game shows 1/2

The counter checks two things: the squad is selected and the goal log matches the score. Check that every goal is logged (opponent goals too). Scorers are not required.

## Performance Issues

### App Running Slowly

**Problem**: The app is sluggish or unresponsive.

**Solutions**:
1. Close other apps running in the background
2. Restart the app
3. Clear app cache in Android settings
4. Archive finished leagues and tournaments

### Timer Not Accurate

**Problem**: The game time seems off.

The clock keeps running while the phone is locked or you use another app. When you come back to MatchOps, the time catches up from the phone's clock.

**Solutions**:
- Make sure the phone's time is set automatically
- Check that the clock was not left paused (the button then shows **Resume**)
- If the referee ended the period early, use **End period** on the large clock

## Display Issues

### Screen Orientation Problems

**Problem**: The layout looks wrong.

**Solutions**:
- MatchOps is made for a phone held upright (portrait)
- Restart the app if the screen stays wrong

### Elements Missing or Cut Off

**Problem**: Can't see all the interface elements.

**Solutions**:
- Check the phone's display settings: reduce the font size or display zoom

## Connectivity Issues

### Offline Mode Not Working

**Problem**: App doesn't work without internet.

**Solutions**:
- Make sure you have opened the app and signed in at least once with an internet connection
- The app downloads the files it needs on first launch
- Try reinstalling the app

<Callout type="tip">
After first launch, the app should work offline. Test by enabling airplane mode and reopening.
</Callout>

## Android-Specific Issues

### Screen Turns Off During a Match

MatchOps keeps the screen on during the match. If it still turns off:
- Make sure the match clock has been started
- Try turning off the phone's battery saver for the match

The clock keeps running even if the screen turns off.

### Microphone Not Working

Voice notes need microphone access. If you denied it, allow it in your phone's app settings.

## Getting More Help

### Before Contacting Support

Gather this information:
1. Device model and Android version
2. App version (**Settings** → **About**)
3. Whether you're signed in to your account
4. Steps to reproduce the issue
5. Any error messages
6. Screenshot if possible

### Reset Options

If issues persist:

1. **Sign out and back in**: Often fixes sync issues
2. **Re-sync from Cloud**: **Settings** → **Data** → Danger Zone; clears the phone's copy and downloads the data again from your account
3. **Soft reset**: Clear app cache in Android settings, then reopen
4. **Clean reinstall**: Uninstall and reinstall the app, then sign back in
5. **Delete All Data**: **Settings** → **Data** → Danger Zone; permanently deletes your data everywhere (last resort)

<Callout type="info">
Legacy note: if you use MatchOps without an account, export a backup before any reset, since there is no cloud copy to re-sync from.
</Callout>

<Callout type="warning">
Always backup your data before attempting any reset procedures.
</Callout>
