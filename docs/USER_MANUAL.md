# MatchOps User Manual

The full user guide lives on the website, in English and Finnish:

- **Suomeksi:** [match-ops.com/guide](https://match-ops.com/guide)
- **English:** [match-ops.com/en/guide](https://match-ops.com/en/guide)

It covers getting started (account, the two-step setup and the first plan), the basic
and full layouts, the plan and **Who is here?**, the game-day workflow and the Match
planner, recording a
match (goals, substitutions, voice notes), finishing a match with the checklist, the
match report for Taso, statistics, teams, leagues and tournaments, backups and
troubleshooting.

*This page used to hold a separate manual. It had fallen behind the app, so the guide
is now the single maintained version.*
